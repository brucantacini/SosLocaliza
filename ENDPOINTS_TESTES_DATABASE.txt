------------------------------------------------------------

4. SEQUENCIA COMPLETA PARA O VIDEO (12 OPERACOES)
================================================================================

Execute nesta ordem no Postman:

1. POST /api/procedures/localizacao
   JSON: Criar Localizacao 1
   Anote: ID_1

2. POST /api/procedures/localizacao
   JSON: Criar Localizacao 2
   Anote: ID_2

3. PUT /api/procedures/localizacao/{ID_1}
   JSON: Atualizar Localizacao 1

4. PUT /api/procedures/localizacao/{ID_2}
   JSON: Atualizar Localizacao 2

5. DELETE /api/procedures/localizacao/{ID_1}
   Body: Vazio

6. DELETE /api/procedures/localizacao/{ID_2}
   Body: Vazio

7. POST /api/procedures/localizacao
   JSON: Criar Localizacao para Usuario
   Anote: ID_LOCAL

8. POST /api/procedures/usuario
   JSON: Criar Usuario 1 (use ID_LOCAL no JSON)
   Anote: ID_USUARIO_1

9. POST /api/procedures/usuario
   JSON: Criar Usuario 2 (use ID_LOCAL no JSON)
   Anote: ID_USUARIO_2

10. PUT /api/procedures/usuario/{ID_USUARIO_1}
    JSON: Atualizar Usuario 1 (use ID_LOCAL no JSON)

11. PUT /api/procedures/usuario/{ID_USUARIO_2}
    JSON: Atualizar Usuario 2 (use ID_LOCAL no JSON)

12. DELETE /api/procedures/usuario/{ID_USUARIO_1}
    Body: Vazio

13. DELETE /api/procedures/usuario/{ID_USUARIO_2}
    Body: Vazio

6. CONFIGURACAO DO POSTMAN
================================================================================

Base URL: http://localhost:8081/api

Headers para todas as requisições:
Content-Type: application/json

Para DELETE: Não precisa de Body

Para POST e PUT: Use o Body > raw > JSON com os JSONs acima


================================================================================
NOTAS IMPORTANTES
================================================================================

1. Todos os endpoints começam com /api
2. Substitua {ID_1}, {ID_2}, {ID_LOCAL}, {ID_USUARIO_1}, {ID_USUARIO_2} pelos IDs retornados
3. Para DELETE, não precisa enviar JSON no body (deixe vazio)
4. As respostas de sucesso sempre retornam: {"id": X, "mensagem": "...", "sucesso": true}
5. Para o vídeo de Database, execute as 12 operações (6 de Localização + 6 de Usuário)
6. Mostre a persistência dos dados no Oracle Database após cada operação (opcional mas recomendado)
7. No Postman, configure a Base URL como variável de ambiente para facilitar
